# Synthetic CMCE data

Generated by `scripts/make_synthetic_cmce.py`.

## Easy (default)

Keeps the original short-phrase behavior (2–3 chunks, regular visual strides).

- `synthetic_train.json` — 200 samples (default)
- `synthetic_val.json` — 40 samples (default)

```bash
python scripts/make_synthetic_cmce.py --seed 42
# equivalent: --difficulty easy --out-prefix synthetic
```

## Hard

Longer multi-chunk texts (3–5+ phrases), confusable/synonym object bank,
irregular visual strides, boundary flip/drop noise, and extra low-confidence
**distractor** rows in `alignments` that are **not** copied into
`alignment_token_pairs` (supervision stays clean; `threshold_acc` gets harder).

- `synthetic_hard_train.json`
- `synthetic_hard_val.json`

```bash
python scripts/make_synthetic_cmce.py --seed 42 --difficulty hard --n-train 300 --n-val 60
# or: --out-prefix synthetic_hard
```

## Schema notes

Each sample includes `alignment_token_pairs` (primary 1:1 visual↔text token
indices for supervised alignment). Secondary / distractor alignments stay in
`alignments` with `"primary": false` (hard may also set `"distractor": true`)
and are **not** included in token pairs.

## Train hard split

```bash
python scripts/train_tiny.py --epochs 8 --device cpu --seed 42 \
  --train-data data/synthetic_hard_train.json \
  --val-data data/synthetic_hard_val.json \
  --out results/tiny_hard_v1
```
