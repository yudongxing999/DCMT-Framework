# Synthetic CMCE data

Generated by `scripts/make_synthetic_cmce.py` (seed=42):
- `synthetic_train.json` — 200 samples
- `synthetic_val.json` — 40 samples

Each sample includes `alignment_token_pairs` (primary 1:1 visual↔text token
indices for supervised alignment). Secondary noisy alignments stay in
`alignments` with `"primary": false` and are **not** included in token pairs.

Regenerate:
```bash
python scripts/make_synthetic_cmce.py --seed 42
```
