# Real matched image-text CMCE (tiny / smoke)

Generated by `scripts/prepare_real_cmce.py` (source=flickr8k).

- Images under `images/` (re-download; **not committed** — regenerate)
- `train.json` / `val.json` in CMCE schema
- **Matched** captions when source is flickr8k / coco (not random picsum)
- Text chunks: noun-phrase heuristic; fallback 2-4 token windows
- **Visual GT is pseudo**: `--grounding clip` scores 4×4 patch crops vs chunk text; fallback LTR
- CLIP cache: `/workspace/hf_cache` / `/workspace/clip_cache`
- See `meta.json` for `source` / `grounding` / `clip_model`

## Regenerate

```bash
pip install datasets Pillow transformers
python scripts/prepare_real_cmce.py --source flickr --out-dir data/real_matched \
  --n-total 100 --seed 42 --grounding clip --max-caption-tokens 12
# or: --source coco / --source auto
```

## Train (real_v4)

```bash
python scripts/train_tiny.py --epochs 8 --device cpu --seed 42 \
  --train-data data/real_matched/train.json --val-data data/real_matched/val.json \
  --token-align-weight 1.5 --visual-boundary-weight 0.25 \
  --out results/tiny_real_v4
```
