# Real image-text CMCE (tiny / smoke)

Generated by `scripts/prepare_real_cmce.py`.

- Images under `images/` (re-download; **not committed** — regenerate)
- `train.json` / `val.json` in CMCE schema
- Text chunks: noun-phrase heuristic (det+adj*+noun+ / prep phrases); fallback 2-4 token windows
- **Visual GT is pseudo**: distinct LTR patch columns (+ optional CLIP with `--use-clip`)
- `alignment_token_pairs` are primary pairs only (consistent with train_tiny supervision)

## Regenerate

```bash
pip install Pillow torchvision
python scripts/prepare_real_cmce.py --n-total 80 --seed 42
# optional CLIP (auto-skipped if heavy/unavailable):
python scripts/prepare_real_cmce.py --n-total 80 --seed 42 --use-clip
# offline:
python scripts/prepare_real_cmce.py --from-dir /path/to/images --n-total 60
```

## Train (real_v2)

```bash
python scripts/train_tiny.py --epochs 8 --device cpu --seed 42 \
  --train-data data/real/train.json --val-data data/real/val.json \
  --token-align-weight 1.25 --out results/tiny_real_v2
```
