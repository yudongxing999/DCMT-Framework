# Real image-text CMCE (tiny / smoke)

Generated by `scripts/prepare_real_cmce.py`.

- Images under `images/` (re-download; not always committed)
- `train.json` / `val.json` in CMCE schema
- **Visual GT is pseudo**: patch indices spaced across the image; no detectors

## Regenerate

```bash
pip install Pillow torchvision  # for image load in evaluate/train
python scripts/prepare_real_cmce.py --n-total 80 --seed 42
# or offline:
python scripts/prepare_real_cmce.py --from-dir /path/to/images --n-total 60
```

## Train

```bash
python scripts/train_tiny.py --epochs 5 --device cpu --seed 42 \
  --train-data data/real/train.json --val-data data/real/val.json \
  --out results/tiny_real_v1
```
