# Real image-text CMCE (tiny / smoke)

Generated by `scripts/prepare_real_cmce.py`.

- Images under `images/` (re-download; **not committed** — regenerate)
- `train.json` / `val.json` in CMCE schema
- Text chunks: noun-phrase heuristic (det+adj*+noun+ / prep phrases); fallback 2-4 token windows
- **Visual GT is pseudo**: `--grounding clip` (default auto) scores 4×4 patch crops vs chunk text; fallback LTR columns
- CLIP weights cache: `/workspace/hf_cache` (transformers) / `/workspace/clip_cache`
- `alignment_token_pairs` are primary pairs only (consistent with train_tiny supervision)
- See `meta.json` for `grounding` / `clip_model` (`spatial_fallback` if CLIP failed)

## Regenerate

```bash
pip install Pillow torchvision
# optional CLIP (preferred): pip install transformers
python scripts/prepare_real_cmce.py --n-total 80 --seed 42 --grounding clip
# spatial only:
python scripts/prepare_real_cmce.py --n-total 80 --seed 42 --grounding spatial
# offline:
python scripts/prepare_real_cmce.py --from-dir /path/to/images --n-total 60
```

## Train (real_v3)

```bash
python scripts/train_tiny.py --epochs 8 --device cpu --seed 42 \
  --train-data data/real/train.json --val-data data/real/val.json \
  --token-align-weight 1.5 --visual-boundary-weight 0.25 \
  --out results/tiny_real_v3
```
