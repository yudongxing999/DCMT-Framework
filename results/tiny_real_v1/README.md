# tiny_real_v1

Tiny real image-text CMCE smoke train (seed=42, epochs=5, CPU).

```bash
python scripts/prepare_real_cmce.py --n-total 80 --seed 42
python scripts/train_tiny.py --epochs 5 --device cpu --seed 42 \
  --train-data data/real/train.json --val-data data/real/val.json \
  --out results/tiny_real_v1
```

Visual alignments are **pseudo** (no detectors). Images under `data/real/images/`
are regenerated by the prep script and not committed. See `metrics.json`.
